The website is static and can be hosted free on GitHub Pages.

Next steps:
1. Create a GitHub account if you do not have one.
2. Create a new public repository, e.g. kashi-kaveri-foods.
3. Upload index.html and style.css.
4. Repository Settings → Pages → Deploy from branch → main → /(root).
5. Save. GitHub will provide a free *.github.io website address.

Before going live, replace the placeholder food-image blocks with actual food photos and add the correct Google Maps/Profile link.
